# Codex Quota

原生 macOS 额度仪表盘，在菜单栏和桌面卡片中显示本机 Codex 的 5 小时与每周额度。

## 构建与运行

要求 macOS 13+ 和 Xcode Command Line Tools。

```bash
./scripts/build-app.sh
open "dist/Codex Quota.app"
```

## 桌面卡片

应用启动后，桌面右上角会出现额度卡片，同时菜单栏会显示剩余额度。桌面卡片的使用方式：

- 拖动卡片可调整位置；退出并重新启动后，应用会恢复上次的位置。
- 鼠标移入卡片后，可以点击“刷新”立即读取最新额度，或点击“隐藏”收起卡片。
- 隐藏后，点击菜单栏中的额度图标，再选择“显示桌面卡片”即可恢复。
- 卡片停留在桌面层：普通应用窗口会盖住它，回到桌面时它会再次可见；它不会覆盖全屏应用。

桌面卡片和菜单栏共用同一份本机数据与刷新任务，不会额外调用模型或消耗 Token。

## 数据与隐私

应用只在本机读取 `~/.codex/sessions/**/*.jsonl` 中的 `rate_limits` 字段，不调用模型、不消耗 Token、不请求网络，也不读取认证令牌。

## 没有数据显示

先在 Codex 中完成一次任务，等待任务生成新的额度记录，然后点击仪表盘中的“刷新”。
