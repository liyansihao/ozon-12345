# Codex 额度桌面悬浮卡片设计

## 目标

在现有 Codex Quota 菜单栏应用中增加一个原生 macOS 桌面悬浮卡片。卡片长期贴在桌面层，可拖动并记住位置，但不遮挡其他应用窗口。

卡片与菜单栏面板共用现有 `QuotaStore` 和本机 JSONL 数据源，不调用模型、不请求网络、不消耗 Token。

## 用户体验

- 应用启动时同时启动菜单栏功能和桌面卡片。
- 卡片首次出现于主屏幕右上角的安全区域。
- 用户可拖动卡片，松手后自动保存屏幕和位置。
- 卡片位于桌面层；普通应用窗口激活后会盖住卡片。
- 切换回桌面时卡片保持可见。
- 卡片显示 5 小时额度、每周额度、剩余百分比和重置倒计时。
- 鼠标移入卡片时显示刷新和隐藏按钮，移出后隐藏操作按钮。
- 菜单栏面板提供“显示桌面卡片”或“隐藏桌面卡片”操作。
- 用户隐藏卡片后，应用记住该状态；可随时从菜单栏恢复。

## 视觉设计

卡片采用紧凑横向布局，建议尺寸约 300 × 150 点：

- 深色半透明材质背景。
- 16 点圆角和轻微阴影。
- 顶部显示 `Codex 额度` 与数据状态。
- 中部并列两个小型进度环，分别显示 5 小时和每周剩余比例。
- 底部显示最近重置倒计时。
- 正常、警告、危险颜色规则沿用菜单栏面板：已用达到 80% 为橙色，达到 95% 为红色。
- 空数据、过期和权限错误状态与菜单栏使用相同文案语义。

## 架构

桌面卡片仍在现有 `CodexQuota` 进程内运行，不创建第二个应用或第二份额度读取循环。

新增单元：

1. `DesktopWidgetController`：创建、显示、隐藏和恢复桌面窗口，持有窗口生命周期。
2. `DesktopWidgetPanel`：`NSPanel` 子类，配置无标题栏、透明背景、桌面层级和跨 Space 行为。
3. `DesktopWidgetView`：SwiftUI 卡片内容，只消费 `QuotaStore` 状态和刷新操作。
4. `WidgetPlacementStore`：用 `UserDefaults` 保存显示状态、屏幕标识和归一化位置。
5. `WidgetPlacement`：负责默认位置、拖动后的坐标换算和屏幕变化后的可见区域修正。

`CodexQuotaApp` 继续拥有唯一的 `QuotaStore`。应用启动所有者把同一个 Store 注入菜单栏视图和桌面卡片控制器。

## 窗口行为

- 使用无边框 `NSPanel`，窗口不激活应用、不抢输入焦点。
- 窗口层级设置到桌面图标附近，使普通应用窗口始终位于卡片之上。
- 卡片允许鼠标拖动和按钮点击，但不会出现在 Dock 或 Command-Tab 中。
- 卡片可出现在所有桌面 Space；进入全屏应用时不覆盖全屏内容。
- 屏幕配置发生变化时重新校验位置。若保存的屏幕不存在或卡片超出可见区域，则移动到主屏幕右上角。

窗口层级属于 macOS 行为细节，实施时需在真实桌面、普通应用窗口、Mission Control、多 Space 和全屏模式中验证。

## 位置持久化

保存：

- 卡片是否显示。
- `NSScreen` 的持久化标识。
- 卡片左下角相对于屏幕可见区域的归一化坐标。

使用归一化坐标而不是绝对像素，可在分辨率或缩放变化后尽量保持相对位置。恢复时始终把完整卡片限制在目标屏幕的 `visibleFrame` 内。

## 数据流

1. 应用启动并创建唯一 `QuotaStore`。
2. 自动刷新所有者立即启动现有 60 秒刷新循环。
3. 菜单栏和桌面卡片同时订阅相同的 `QuotaLoadState`。
4. 用户在任一界面点击刷新，都调用同一个 `QuotaStore.refresh()`。
5. 用户拖动卡片后，控制器将新位置交给 `WidgetPlacementStore` 保存。

桌面功能不增加新的文件扫描频率。

## 错误处理

- 没有额度数据：卡片显示等待 Codex 新数据。
- 数据过期：继续展示最近一次快照，并显示过期标记。
- 权限或读取失败：展示简短错误状态，菜单栏保留完整说明。
- 保存位置损坏：忽略损坏值并回到主屏幕右上角。
- 目标屏幕断开：回到主屏幕右上角，不把窗口留在不可见区域。

## 测试与验收

单元测试覆盖：

- 首次启动默认位置为主屏幕右上角。
- 拖动位置保存和恢复。
- 归一化坐标在分辨率变化后正确换算。
- 超出屏幕的位置被限制回可见区域。
- 保存屏幕不存在时回退到主屏幕。
- 隐藏状态保存，菜单栏恢复后更新状态。
- 菜单栏与卡片共享同一个 Store，不创建第二个刷新循环。

人工验收：

1. 启动应用后卡片出现在桌面右上角。
2. 拖动后退出并重新启动，卡片恢复到上次位置。
3. 打开普通应用窗口时，应用窗口盖住卡片。
4. 回到桌面后卡片仍可见。
5. 点击隐藏后卡片消失，从菜单栏可恢复。
6. 拔掉卡片所在外接屏幕后，卡片回到主屏幕可见区域。
7. 进入全屏应用时卡片不覆盖全屏内容。
8. 活动期间没有网络请求或额外额度读取循环。

## 非目标

本次不实现 WidgetKit 原生通知中心组件、不支持多张卡片、不增加皮肤编辑器、不增加开机自动启动、不增加通知提醒，也不改变现有额度数据来源。
