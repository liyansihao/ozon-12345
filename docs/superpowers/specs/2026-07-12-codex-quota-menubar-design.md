# Codex 额度菜单栏仪表盘设计

## 目标

构建一个原生 macOS 菜单栏应用，自动读取本机 Codex 产生的额度记录，让用户无需打开 Codex 设置页即可查看 5 小时额度和每周额度。

首个版本只读取本机真实数据，不提供手动填写、不请求网络接口，也不上传账号、令牌或会话内容。

## 用户体验

- 应用常驻 macOS 菜单栏，不在 Dock 中显示常规应用图标。
- 菜单栏标题显示当前最紧张额度的剩余百分比，例如 `◉ 82%`。
- 点击菜单栏标题后打开紧凑面板。
- 面板分别显示“5 小时额度”和“每周额度”。
- 每项额度包含已用百分比、剩余百分比、进度环和距离重置的时间。
- 面板显示额度名称、数据最后更新时间和手动刷新按钮。
- 额度使用率低于 80% 时使用正常色，达到 80% 时使用警示色，达到 95% 时使用危险色。
- 菜单栏标题使用两项额度中剩余比例更低的一项，使最迫近的限制始终可见。

## 技术方案

使用 Swift、SwiftUI 和 `MenuBarExtra` 构建原生 macOS 应用，最低支持 macOS 13。

项目独立放在仓库根目录的 `codex-quota-menubar/`，不修改现有 Ozon 自动化流程。使用 Swift Package Manager 管理和构建，首个版本不引入第三方依赖。

应用由以下边界清晰的单元组成：

1. `CodexSessionLocator`：在 `~/.codex/sessions/**/*.jsonl` 中定位最近更新的会话文件。
2. `RateLimitParser`：从 JSONL 尾部向前查找最新的 `rate_limits` 数据，只解析额度相关字段。
3. `QuotaSnapshot`：承载额度名称、主窗口、次窗口、重置时间和数据时间戳。
4. `QuotaStore`：协调读取、定时刷新、状态发布和错误降级。
5. `MenuBarView`：渲染菜单栏标题与弹出面板，不直接访问文件系统。

## 数据来源与解析规则

Codex 会话 JSONL 中的 `event_msg` 可能包含 `payload.rate_limits`。首个版本读取：

- `limit_id`
- `limit_name`
- `primary.used_percent`
- `primary.window_minutes`
- `primary.resets_at`
- `secondary.used_percent`
- `secondary.window_minutes`
- `secondary.resets_at`

解析器按文件修改时间由新到旧检查，并在每个文件内从最后一行向前寻找完整额度记录。找到第一条可解析记录后停止。百分比限制在 0–100 范围内；Unix 秒时间戳转换为本地时间。

界面名称根据窗口长度确定：300 分钟显示为“5 小时额度”，10080 分钟显示为“每周额度”。若窗口长度改变，则显示由分钟数生成的通用名称，避免误标。

## 刷新流程

应用启动后立即读取一次，并每 60 秒自动刷新。用户点击刷新按钮时立即再次读取。

文件扫描和 JSON 解析在后台任务中执行，界面状态只在主线程更新。一次刷新最多读取有限数量的最新文件和每个文件的有限尾部内容，避免历史会话较多时拖慢菜单栏。

成功读取后更新快照和最后更新时间。读取过程中继续展示上一份成功快照，避免界面闪烁。

## 错误与隐私

- 未找到会话目录或额度记录：显示“等待 Codex 新数据”，并提示先在 Codex 中运行一次任务。
- 最新文件尚在写入或尾行不完整：跳过损坏行并继续向前查找，不让整个刷新失败。
- 权限不足：显示无法读取本机 Codex 数据的明确提示。
- 已有快照后发生读取失败：保留旧数据并标记“数据可能已过期”。
- 重置时间已经过去但尚无新记录：显示“等待额度刷新”，不自行推断新的使用率。

应用只读取额度字段，不保存或展示提示词、回复、工具调用、认证令牌或其他会话内容。首个版本不发起任何网络请求。

## 测试与验收

单元测试覆盖：

- 从有效 JSONL 解析主、次额度窗口。
- 忽略无关事件、空行和损坏行。
- 多条额度记录中选择最后一条有效记录。
- 多个会话文件中优先选择最新有效数据。
- 百分比边界处理、剩余比例计算和重置倒计时。
- 无文件、无权限和只有旧快照时的状态降级。

人工验收标准：

1. 应用启动后出现在菜单栏且不显示普通 Dock 图标。
2. 在本机现有 Codex 数据上展示真实的 5 小时与每周使用率。
3. 菜单栏显示两项额度中更低的剩余百分比。
4. 点击后能看到两项进度、重置倒计时和最后更新时间。
5. 新的 Codex 额度记录出现后，界面在 60 秒内更新。
6. 暂时移走数据目录后应用不崩溃，并显示可理解的空状态。

## 非目标

首个版本不包含 API 费用、Token 统计、手动额度校准、跨设备同步、通知提醒、登录项设置、App Store 发布或自动更新。这些能力可在核心读取链路验证稳定后独立评估。
